# Fastify + Pnpm + Typescript + PostgreSQL/Kysely + Authentication with JWT + Cloudinary(File upload) + Swagger OpenAPI

To install dependencies:

```bash
pnpm install
```

To run:

```bash
pnpm run dev (Development)
pnpm run build + pnpm start (Production)
```

Database:

```bash
pnpm run migration:create + name_migration (create new migration)
pnpm run db:migrate (migrate database)
```

This project was created using `pnpm init`. [Pnpm](https://pnpm.io) is a fast all-in-one JavaScript runtime.
